## 📁 Estrutura e Aplicações

Cada diretório contém uma aplicação focada na resolução de um problema de negócio específico:

### 🍕 1. [vendas-pizza/](vendas-pizza/App_vendas_pizza.py)
- **Descrição**: Sistema de pedidos de pizzaria com menu dinâmico, seleção de sabores, tamanhos e cálculo acumulativo de valores com validação contínua de entrada.
- **Conceitos**: Laços de repetição (`while/for`), condicionais aninhadas e tratamento de strings.

### 📇 2. [agenda-contatos/](agenda-contatos/Lista_contato.py)
- **Descrição**: Gerenciador de contatos em memória via terminal.
- **Funcionalidades**: Cadastro com ID único, consulta (por ID ou lista completa), remoção e modularização por funções.
- **Conceitos**: Dicionários, listas, funções com parâmetros e escopo de dados.

### 🌲 3. [calculadora-madeireira/](calculadora-madeireira/Madereira.py)
- **Descrição**: Sistema comercial para cálculo de precificação de madeira com faixas de desconto progressivo por quantidade e taxa de transporte por rota.
- **Conceitos**: Funções modulares, validações numéricas e tabelas de decisão.

### 🏥 4. [cotacao-plano-saude/](cotacao-plano-saude/PlanosDeSaude.py)
- **Descrição**: Calculadora de mensalidade de plano de saúde com base na idade do contratante e tabela atuarial básica.
- **Conceitos**: Estruturas de controle de fluxo e operadores relacionais.

---
